## بليغ | Baleegh

### Arabic Language × AI

**Baleegh** is my flagship project exploring how computational systems can understand, analyze, and work with the structure of the Arabic language.

It combines linguistic rules with software engineering to build an Arabic-first foundation for language technology.

<div align="center">

**كَتَبَ** → **كَاتِب** → **مَكْتُوب**

*Root · Pattern · Morphology · Derivation*

</div>

### What Baleegh explores

| Area | Focus |
| --- | --- |
| **الاشتقاق** | Generate and explore Arabic derivatives from roots and morphological patterns |
| **معلومات الكلمة** | Morphological and grammatical word analysis |
| **تقطيع** | Arabic tokenization and clitic segmentation |
| **التصريف** | Arabic verb conjugation across forms and tenses |

> The goal is not only to process Arabic text, but to build a linguistic foundation that AI systems can build upon.

[**Explore Baleegh →**](https://www.baleegh.ai/)

## Why Arabic NLP?

Arabic carries substantial linguistic information in the internal structure of a word.

Roots, patterns, morphology, derivation, prefixes, suffixes, and grammatical features all contribute to meaning.

My work focuses on making that structure computationally accessible.
